yt-dlp 下载视频很方便，但每次都要输入命令、查找参数，多少有些麻烦。所以我做了 YTDL Mate（YT下载助手），一个面向 Windows 的轻量中文图形界面。

使用方式很直接：粘贴链接，选择画质和保存位置，点击下载。支持批量链接、播放列表，以及提取 MP3、M4A 音频。视频默认保存为 MKV，也可以切换到 MP4，还能按需下载中英字幕、嵌入封面和媒体信息。

对于需要登录的内容，可以读取浏览器登录信息，或导入 cookies.txt。解析链接后还能查看实际可用的分辨率，不过最终能下载什么画质，仍取决于视频源和账号权限。

程序采用 Python + Tkinter 编写，提供免安装 EXE。使用前需要准备 yt-dlp、FFmpeg、ffprobe，以及用于部分网站的 Deno，下载链接和配置步骤都整理在项目 README 中，有需要的可以去github自行[下载](https://github.com/YIF4NG/ytdl-mate)。

它的目标很简单：把常用的下载操作放进一个窗口，让保存视频和音频更省事。
