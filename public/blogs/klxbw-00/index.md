# 一、高中：在分数排名里打转
高中三年，我在杭州。这座城市有好学校，也有好卷子。身边所有人都在做同一件事：把分数往上挪。三位一体、综合评价、赋分制、哪家补课机构更好——这些词构成了我们全部的日常。

其实智力差距没有那么大。大多数人之间的分数，不过是一两道选择题的差距。但学校依然会把每个人的成绩投在礼堂大屏幕上，荣耀和耻辱都无处可藏，像一个巨大的审判现场。我学会的不是知识，而是如何在这种评价体系里尽量不让自己太难看。

同时，有些东西从来没人教：怎么和人相处，怎么判断一个人是否值得交往，怎么区分喜欢和表演。没人教，也没人在意。大家关心的是你模考排第几，能上哪所学校。

# 二、杭州：木气氤氲的城市
杭州是一座复杂的城市。

消费水平高，房价高。但同时，这里有最前沿的科创公司，有安静藏在市中心的寺庙和茶山，有把时尚和品味刻进日常的人群。有人描述这座城市“木气重”——滋养创意，也滋生欲望。

很多高中生甚至更小的孩子，刷着短视频，看着网红光鲜的生活，快速积累财富、被人追捧。这种生活看上去来钱快、事少、有影响力，很难不让人心动。于是我们这一代人的焦虑分成了两层：一层来自分数，一层来自“为什么别人可以活得那么轻松”。

杭州教会我的是：这座城市永远在给你看更好的东西，然后问你——你配不配得上。

# 三、眼界打开之后：香港、江西、湖南
我是商科学生。去年暑假，我在香港待了一个月，转头又去了江西和湖南。

观察劳务报酬，差距是三到四倍。房价，是十倍不止。汇率、税收、产业布局——所有这些宏大的词，落实到具体生活里就是：同一种劳动，在不同城市值不同的钱。

萍乡几乎没有龙头企业，年轻劳动力被虹吸到长沙。这个现象不复杂，商业逻辑就能解释。但真正让我有感触的，是当地人的生活节奏、习惯、那种“快”与“慢”的差异。到了发达城市，你会发现世界都差不多——地铁上的人们各自低头，人种差异并不构成什么实质壁垒，学好一门语言，或者用好AI，就能相对顺畅地融入。

说到底，移动和生存需要的只是机票钱和覆盖食宿的收入。

见识打开之后，反而感到一种更深的虚无——世界其实是一个巨大的同质化系统，表面的差异，经不起细看。

# 四、大学恋爱：祛魅的过程
大学里，恋爱像一门显学。

大家物色形象不错、聊得来的人，开始考察：对方是否值得托付，有没有在表演，有多喜欢自己，合不合适，自己的配得感够不够，彼此是哪种依恋人格。

不能太早暴露目标感，要等感情升温到一个合适的节点再捅破窗户纸；太早容易崩，太晚容易错过。也有人干脆不看这么多——别人谈我也谈，谈累了就分。

我逐渐觉得，很多关系的本质是价值交换。付出、礼物、感动、纠缠……在多巴胺消退之后，往往变成累赘。看到那些曾经感动过自己的东西，甚至会觉得厌烦和恶心。

没有人靠近你是为了让你幸福。这句话我至少现在愿意相信。虽然它不足以概括所有人性，但至少解释了很多让我困惑的事。

爱是什么呢？我觉得更像是自身人格的外溢——在你拥有饱满的人格、有自己的爱好、基因协调表达、有对生活的基本判断和规划、对自己有清晰认知之后，自然流露出来的东西。

你得有一些优点，足够保持积极，抵消负面的部分。否则，一段关系只会加速消耗你。

# 五、祛魅之后，还剩下什么
说了这么多，我最想说的是：

人生很多时候是无聊的。小时候想吃的好东西、想去的地方、想拥有的东西，真正得到之后，很快就觉得“不过如此”。

好吃的好玩的，到后来就那样。没有任何外在的东西能真正充实一个人的内心。你只能专注自己的生活，接受自己，成为那个想成为的自己。这样你才能享受命运给你的奖赏，也承受命运给你的惩罚。

命运反复出题，只想看到一颗真正坚定的心。

很多事情没人教，需要自己学。但个人进步，永远是所有问题的最优解。

所以祝你找到一个人生中闪闪发光的终点，为之奋斗。那是最大的幸福。
